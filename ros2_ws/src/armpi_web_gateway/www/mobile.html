로봇 전체 (rosbridge 서비스)

빨간 비상정지 버튼은 Protocol v3 비상정지다. "로봇 전체 정지"는 rosbridge 서비스(/armpi/emergency_stop)라 따로 "전체 해제"해야 풀린다. 물리적 정지(전원 스위치)는 항상 손 닿는 곳에 둔다.
